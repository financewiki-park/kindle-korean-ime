킨들 한글 키보드 설치 안내

이 문서는 탈옥된 Kindle에서 Korean IME를 설치하고, 홈 화면의 아이콘으로 다시 실행하는 방법을 설명합니다.

주의

이 패키지는 현재 개발·검증 단계입니다. Kindle 5.19.6, kindlehf 환경에서 확인한 결과를 바탕으로 합니다. 다른 모델과 펌웨어에서는 호환성 확인이 필요합니다. 탈옥과 서드파티 패키지 사용에는 기기 오작동 또는 데이터 손실 위험이 있습니다.

준비물

- 탈옥된 터치 Kindle
- KTerm
- KPM
- SH Integration
- Wi-Fi 연결

SH Integration은 .sh 실행 파일을 Kindle 홈 라이브러리의 실행 항목으로 표시해 주는 구성요소입니다. 이미 다른 .sh 실행 파일이 홈 화면에 보인다면 준비된 상태입니다.

1. KPM에 저장소 등록하기

KTerm을 열고 아래 한 줄을 실행합니다.

/var/local/kmc/bin/kpm add-repo https://financewiki-park.github.io/k/

저장소는 한 번만 등록하면 됩니다.

등록됐는지 확인하려면 아래 명령을 실행합니다.

/var/local/kmc/bin/kpm list-repo

목록에 korean-ime 또는 Kindle Korean IME가 보이면 정상입니다.

2. 패키지 목록 갱신하기

/var/local/kmc/bin/kpm update

3. Korean IME 설치하기

/var/local/kmc/bin/kpm install korean-ime

처음 설치할 때는 순서대로 아래 세 줄을 실행하면 됩니다.

/var/local/kmc/bin/kpm add-repo https://financewiki-park.github.io/k/
/var/local/kmc/bin/kpm update
/var/local/kmc/bin/kpm install korean-ime

설치 중에는 Kindle을 재부팅하거나 USB 케이블을 뽑지 마세요.

4. 홈 화면에서 실행하기

설치가 끝나면 Kindle USB 저장소의 documents 폴더에 Korean IME Start.sh 실행 파일이 만들어집니다.

SH Integration이 설치된 기기에서는 홈 화면 라이브러리가 새로고침된 뒤 Korean IME Start가 한글 키보드 아이콘과 함께 나타납니다.

재부팅 뒤에는 홈 화면에서 Korean IME Start 아이콘을 한 번 누르면 됩니다.

아이콘이 바로 보이지 않으면 USB 연결을 해제한 뒤 잠시 기다려 Kindle 라이브러리 색인이 끝나도록 하세요. 그래도 보이지 않으면 SH Integration 설치 여부를 확인하세요.

임시로 KTerm에서 직접 실행하려면 아래 명령을 사용합니다.

sh '/mnt/us/documents/Korean IME Start.sh'

5. 한글과 영문 전환

현재 빌드에서는 Shift+Space로 한글 조합 처리와 영문 처리를 전환합니다.

기기에 지구본 키가 보이면 Kindle의 키보드 전환에도 사용할 수 있지만, 표시와 동작은 펌웨어에 따라 다를 수 있습니다.

6. 업데이트

새 버전이 나오면 아래 두 줄을 실행합니다.

/var/local/kmc/bin/kpm update
/var/local/kmc/bin/kpm install korean-ime

7. 삭제하고 원래 상태로 되돌리기

/var/local/kmc/bin/kpm uninstall korean-ime

삭제하면 이 패키지가 만든 실행 파일과 아이콘, 실행 중인 한글 조합 브리지를 정리하고 설치 전 백업한 키보드 설정으로 되돌립니다.

문제가 생기면

- 설치가 실패하면 먼저 kpm update를 실행한 뒤 다시 설치하세요.
- 홈 화면에 아이콘이 없으면 SH Integration과 Kindle 라이브러리 색인 상태를 확인하세요.
- 한글이 ㅈㅗㅇ처럼 자모 단위로 입력되면 이전 조합 브리지가 남았을 수 있습니다. 최신 버전으로 다시 설치한 뒤 Korean IME Start를 실행하세요.
- 원래 상태로 되돌리려면 kpm uninstall korean-ime를 실행하세요.

기존 Kingul과의 차이

Kingul은 Kindle 한글 입력을 가능하게 만든 선행 프로젝트입니다. 한글은 ㅎ -> 하 -> 한처럼 입력 중 글자가 계속 바뀌므로 단순 키보드 배열만 추가해서는 제대로 입력할 수 없습니다.

Kingul은 활성 입력창의 키 이벤트를 관찰하고, 표시된 자모를 지운 뒤 조합된 글자를 다시 넣는 방식으로 이를 해결했습니다. Korean IME도 Kindle 기본 입력창에서 한글 조합을 처리한다는 큰 방향은 같습니다.

설치 방식

Korean IME는 KPM에서 저장소를 등록하고 설치·업데이트·삭제합니다.
Kingul은 README 기준으로 MRPI 패키지를 설치한 뒤 KUAL 메뉴를 사용합니다.

실행 방식

Korean IME는 홈 화면의 Korean IME Start 아이콘 또는 KTerm에서 실행합니다.
Kingul은 KUAL의 Kingul 메뉴에서 키보드 선택을 전환합니다.

배포 방식

Korean IME는 kindlehf와 kindlepw2 ARM 바이너리를 하나의 KPM 패키지에 포함합니다.
Kingul은 MRPI 기반 설치 패키지 중심입니다.

한글 조합

Korean IME는 별도 Hangul core로 초성·중성·종성·복합 모음·복합 종성·조합 중 Backspace를 테스트합니다.
Kingul은 Kindle 이벤트를 후처리하는 방식으로 한글 조합을 처리합니다.

최신 Kindle 포커스 처리

최근 Kindle GTK 입력기는 탭마다 내부 포커스 창을 바꿀 수 있습니다. 이를 일반적인 입력창 전환으로 처리하면 조합 상태가 초기화돼 ㅈㅗㅇ처럼 자모가 분리될 수 있습니다.

Korean IME는 창 번호가 바뀌어도 조합 중인 글자 상태를 유지하도록 수정했습니다. 이 부분이 자모 분리 입력 문제를 해결하는 핵심입니다.

전력과 안전성

Korean IME는 부팅 때 자동 실행되지 않습니다. 필요할 때 Korean IME Start를 눌러 실행합니다. 실행 중에는 40ms 유휴 대기를 사용해 불필요한 CPU 사용을 줄입니다.

또한 설치 전 키보드 설정을 백업하고, 업데이트 때 기존 조합 브리지를 종료하며, 삭제 때 설정을 복원합니다.

한계

Kindle 기본 입력 체계에는 공개된 정식 IME API가 없습니다. Korean IME도 기존 입력을 관찰하고 필요한 삭제·재입력을 보내는 호환 계층입니다. 아직 확인되지 않은 모델·펌웨어나 복잡한 편집 동작에서는 예외가 생길 수 있습니다.
